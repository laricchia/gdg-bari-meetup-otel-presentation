Il Problema

La Black Box

Un sistema software in produzione è spesso una scatola nera: riceve input, produce output, ma non sai cosa succede dentro.

Quando qualcosa va storto, le domande tipiche sono:

Building block

Cos'è uno Span?

Uno span rappresenta una singola unità di lavoro. È il mattone fondamentale del tracing.

▸Name — nome dell'operazione
▸Trace ID — identifica la trace padre
▸Span ID — identifica univocamente lo span
▸Start / End time — durata precisa
▸Attributes — metadati chiave-valore
▸Status — Unset / Error / Ok
▸Parent Span ID — vuoto se root span
Kotlin Android — creare uno span
// Ottieni il tracer dal RUM
val tracer = OpenTelemetryRum
  .tracer("my-tracer")
// Crea e avvia uno span
val span = tracer
  .spanBuilder("fetchOrders")
  .startSpan()
try {
  span.setAttribute(
    "user.id", userId
  )
  // ... logica app ...
} finally {
  span.end()
}

Distributed Tracing

Cos'è una Trace?

Una trace registra il percorso di una singola richiesta attraverso più servizi. È composta da uno o più span collegati dallo stesso trace_id.

In pratica

OTel su Android & Kotlin

🎯 opentelemetry-kotlin (OTel)
Implementazione Kotlin Multiplatform dell'API OTel. Supporta la modalità compatibility con la SDK per Java
github.com/open-telemetry/opentelemetry-kotlin
Setup — Application.kt
val rum = OpenTelemetryRum
 .builder(this, config)
 .addSpanExporterCustomizer {
  OtlpHttpSpanExporter
   .builder()
   .setEndpoint(collectorUrl)
   .build()
 }
 .addTracerProviderCustomizer {
  builder, _ ->
  builder.addSpanProcessor(
   BatchSpanProcessor
    .builder(otlpExporter)
    .build()
  )
 }
 .build()

Il valore

Perché adottare OTel?

🔓
Nessun vendor lock-in
Modifica il codice una volta sola. Puoi cambiare il database/visualizzatore senza doverlo toccare.
🌍
Standard de-facto
Integrato in Kubernetes, Spring Boot, Android, GitHub...
🤖
Auto-instrumentation
Zero-code per OkHttp, Fragment, Activity lifecycle su Android. Pochissime modifiche al codice dell'app.
📡
3 segnali unificati
Traces + Metrics + Logs in un unico SDK. Correlazione automatica tra i segnali per la root cause analysis.
